# Матрица физических демонстраций

Цель этого каталога — дать каждой заявленной механике собственный воспроизводимый физический опыт. Общая запись по умолчанию: GIF длительностью не менее 17,6 с и не менее 176 сохранённых физических состояний — вдвое длиннее и детальнее предыдущей записи `live-support.gif` (8,8 с, 88 кадров). MP4 и исходный CSV сохраняются для поиска и измерений. Кадры нельзя дублировать или интерполировать вместо реально рассчитанных состояний.

Сцена задаёт начальные и граничные условия, но не подменяет механику специальным правилом. Физическое поведение должно идти через публичный API движка. Каждый опыт сообщает измеряемые величины и критерий успешного результата; отрицательный результат тоже сохраняется.

## Правила закрытия строки

Строка считается закрытой только после появления: публичного engine API для механики; отдельной сцены, которая использует этот API; CSV из фактического физического расчёта; GIF и MP4 из сохранённых состояний; численных метрик и ограничений в `PROGRESS_2026-10-12.md`. Для производительных опытов отдельно указываются железо, размер сцены, настройки решателя и измеряется именно физический шаг.

Дальше исправить проход тела сквозь пол и добиться поддержанного контактного опыта. Полная термомеханика, жидкое течение и повторное затвердевание остаются открытыми; разрушение и связность предшествуют опытам с фрагментами. Стабильный engine API нужен для агрегации и GPU-пути. Цели 30 FPS CPU и 60 FPS GPU остаются открытыми, пока их не покажет замер полного физического расчёта.
