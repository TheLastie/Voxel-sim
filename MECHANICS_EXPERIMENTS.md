# Матрица физических демонстраций

Цель этого каталога — дать каждой заявленной механике собственный воспроизводимый физический опыт. Общая запись по умолчанию: GIF длительностью не менее 17,6 с и не менее 176 сохранённых физических состояний — вдвое длиннее и детальнее предыдущей записи `live-support.gif` (8,8 с, 88 кадров). MP4 и исходный CSV сохраняются для поиска и измерений. Кадры нельзя дублировать или интерполировать вместо реально рассчитанных состояний.

Сцена задаёт начальные и граничные условия, но не подменяет механику специальным правилом. Физическое поведение должно идти через публичный API движка. Каждый опыт сообщает измеряемые величины и критерий успешного результата; отрицательный результат тоже сохраняется.

## Реестр

| Механика | Отдельный опыт и наблюдение | Состояние |
|---|---|---|
| Электропроводимость и диэлектрический отклик | Электрический потенциал на паре/решётке REV; ток, сопротивление и накопленный заряд в зависимости от состава | Не реализовано |
| Магнитный отклик материала (опционально) | Материал в заданном внешнем поле; намагничивание и сила/энергия поля | Не реализовано |
| Масса, гравитация, опора и контакт | Падение тела на пол: траектория, импульс, отскок/потеря энергии и дрейф закрепления | Запись 1 680 шагов / 176 кадров готова; провал: куб проходит сквозь пол, нужен фикс контакта |
| Упругая анизотропия и прочность при растяжении | Одинаковые образцы дерева вдоль и поперёк волокон; сила, деформация и начало разрыва | Есть расчёт `experiments::tension`; нужна самостоятельная длинная запись |
| Сжатие и предел текучести | Продольное и поперечное сжатие с кривой усилие–укорочение и остаточной деформацией | Есть расчёт `experiments::compression`; нужна самостоятельная длинная запись |
| Сдвиг и изгиб | Сдвиговой образец и трёхточечный изгиб; поперечный прогиб, сила и разрушенные связи | Есть `experiments::bending`; отдельная наглядная запись отсутствует |
| Контакт инструмента и рез | Удар и проход клина/ножа; контактная сила, импульс, повреждение и связность образца | Есть `knife_capture`; полный переруб ранее не подтверждён |
| Хрупкое, вязкое и усталостное разрушение | Три образца с разными режимами материала; кривая повреждения и форма осколков | Нет завершённой сравнительной серии |
| Распространение трещины и энергия разрушения | Начальный надрез и контролируемая нагрузка; фронт трещины и энергетический бюджет | Частично покрыто клином/ножом; высвобождение энергии не замкнуто |
| Фрагменты, масса и импульс | Разрыв связей до нескольких кластеров и последующие столкновения; баланс массы/импульса каждого кластера | Нет подтверждённого опыта с полным балансом |
| Тепловая проводимость | Горячая и холодная половины железного стержня; профиль температуры и сохранение внутренней энергии | `thermal_capture` физически показал выравнивание; относительная ошибка энергии `4,52×10⁻⁷`; GIF/MP4 по 176 кадров |
| Энтальпия и фазовые переходы | Нагрев/охлаждение воды и металла через плато плавления/кипения; температура и доли фаз | Есть текстовый `thermo_probe`; нужна динамическая GIF-запись и энергетический отчёт |
| Тепловое расширение и температурная прочность | Нагрев зажатого/свободного образца; расширение, термонапряжение и изменение порога разрушения | Не реализовано |
| Составы, смешивание и сплавы | Соединение двух компонент; массовые доли и производные свойства смеси | Не реализовано как процесс объединения |
| Сварка, адгезия и восстановление связи | Контакт металла при нагреве, клеевого соединения либо сращивание после разреза; прочность новой связи | Не реализовано |
| Химическая реакция и горение | Пара материалов с заданной таблицей реакции; расход реагента, продукты, тепло и масса | Не реализовано |
| Мировые барьеры | Выход REV через каждую грань области; удаление на границе шага и ledger массы, импульса, энергии | API/ledger есть; нужна самостоятельная запись и баланс |
| Сцена и ограничения API | Создание сцены из компонент, фиксация/освобождение и изменение топологии; кэши и связность после мутаций | Есть `engine_api_probe`; нужна наглядная запись |
| Жидкость, вязкость и текучесть | Наклон/удар образца при разных фазах; форма, скорость релаксации и сохранение массы | Не реализовано |
| Активная зона и агрегация | Дальняя однородная область агрегирована, область удара детализируется; ошибка и переходы LOD | Не реализовано |
| GPU-физика | Та же физическая сцена на CPU и GPU; состояния, невязка, точность, время шага и загрузка устройства | Есть только CUDA operator probes; физического GPU-решателя нет |
| Производительность CPU | Серия растущих физических сцен с одинаковыми настройками; FPS, невязка и качество результата | Замерен малый профиль; 30 FPS не достигнут |

## Правила закрытия строки

Строка считается закрытой только после появления: публичного engine API для механики; отдельной сцены, которая использует этот API; CSV из фактического физического расчёта; GIF и MP4 из сохранённых состояний; численных метрик и ограничений в `PROGRESS_2026-10-12.md`. Для производительных опытов отдельно указываются железо, размер сцены, настройки решателя и измеряется именно физический шаг.

Сначала завершить текущую длинную механическую запись и валидировать теплопроводность. Затем закрывать строки по зависимостям: общая термомеханика и энергетический ledger предшествуют плавке/сварке; разрушение и связность — опытам с фрагментами; стабильный engine API — агрегации и GPU-пути. Цели 30 FPS CPU и 60 FPS GPU остаются открытыми, пока их не покажет замер полного физического расчёта.
