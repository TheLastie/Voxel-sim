# Живой просмотр: справка разработчика

Основной пользовательский путь для физически видимой сцены — открыть обычный
авторский документ в нативном редакторе:

```powershell
voxel-editor --scene scenes/impact.vxscene
```

Scene открывается в том же редакторе, где можно выбрать объект или воксели,
посмотреть и изменить поддерживаемые параметры в инспекторе и сохранить
`.vxscene`. Отдельное окно просмотра тестов не является режимом продукта.
Описание обычного scene workflow находится в [SCENE_EDITOR.md](SCENE_EDITOR.md).

## Дополнительный диагностический просмотр

`voxel-test-viewer` и `validation/run-visible-test.ps1` остаются инструментами
для разработчика, когда нужно следить за выводом существующего probe или
тестового процесса. Это дополнительная диагностика, не обязательный этап
пользовательского сценария и не замена scene editor. Браузер и HTTP-сервер
для этого не требуются.

Пример запуска диагностического probe:

```powershell
./validation/run-visible-test.ps1 -Executable ./target/release/world_contact_probe.exe -TestArguments @('--adaptive','--steps','100') -Label 'Падение бруска'
```

Путь диагностического просмотра должен показывать только полученные данные
запуска. Не следует описывать его как редактор сцены или приписывать ему
результаты, которых нет в реальном выводе процесса.

Если `VOXEL_LIVE_TESTS_DIR` включён, публикация снимков и их просмотр
потребляют ресурсы. Замеры с этим наблюдателем нужно помечать отдельно;
частота окна не равна частоте физического расчёта и сама по себе не
подтверждает производительность решателя.
