# Задача второго агента: опыт мировых границ

## Цель

Создать отдельный воспроизводимый физический опыт для уже существующего
engine API мировых границ, чтобы он стал дополнительным выбором эксперимента в
viewer и подтверждал удаление REV вместе с граничным ledger.

## Рабочие файлы

- Новый самостоятельный capture binary в `src/bin/`.
- Новая запись CSV и 3D GIF/MP4 в `validation/`.
- `validation/experiments.json` — добавить пункт после готового capture.
- `MECHANICS_EXPERIMENTS.md` — отметить опыт как записанный только после
  проверки фактического результата.

## Критерии

- Сцену собрать через публичный API движка, без собственной физики в capture.
- Записать минимум 176 реально рассчитанных состояний в опыте длиной не менее
  17,6 с при 10 FPS; не дублировать и не интерполировать кадры.
- Показать REV, пересёкшие заданные грани, и измеряемые mass/momentum/energy
  ledger; сохранить CSV, GIF и MP4.
- Использовать уже работающий live viewer на порту 8765; не останавливать его.
- Не редактировать `src/solver.rs`, `src/cuda_solver.rs` или `src/cuda/pcg.ptx`.
- Не менять `PROGRESS_2026-10-12.md`: основной агент объединит результаты в
  общий отчёт.

## Отчёт

Вернуть список изменённых файлов, команды, настройки сцены, число реальных
кадров и ledger-метрики. Явно описать любые физические или визуальные сбои.
