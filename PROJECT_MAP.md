# Карта проекта — вход для разработчика и пользователя движка

Документ — навигация. Он ничего не объявляет готовым: статус и измерения находятся в
`VALIDATION_2026-11-05.md`, требования — в `WORLD_PARADIGM.md` и `DECISIONS_2026-11-05.md`,
план работ — в `INTEGRATION_PLAN_2026-11-05.md`.

## Что это

Rust-движок воксельной физической песочницы. Мир состоит из элементарных объёмов (REV) по
1 см; свойства выводятся из массы, состава и внутренней энергии, температура — из энергии.
Разрушение, трение, нагрев, горение, дубление, гниение, рост растений и управление
существами идут через общие законы, а не сценарии. Главный язык описания целей —
`WORLD_PARADIGM.md`.

## Как запустить

| Что | Команда |
| --- | --- |
| Редактор | `cargo run --release --bin voxel-editor` |
| Открыть сцену | `voxel-editor --scene scenes/<имя>.vxscene` |
| Сцена с анимированной моделью на полу | `voxel-editor --create-animated-scene <путь>.vxscene --animated-model <модель>.vxm` |
| MCP-сервер редактора | `cargo run --release --bin voxel-editor-mcp` (`mcp/README.md`) |
| Бенчмарк ступеней 1k/16k/50k | `cargo run --release --no-default-features --bin active_rev_ladder -- --sides 8,20` |
| Справка по клавишам в окне | `F1` |

Pause (Space) оставляет полное физическое состояние в сцене; File → Save Physical State
пишет `<сцена>.vxstate`, Load Physical State продолжает; `R` сбрасывает к `.vxscene`
(`SCENE_EDITOR.md`).

## Как проверять

- Все тесты: `cargo test --release` (долго; полный прогон нужен перед коммитом).
- Только то, что затронуто: `cargo test --release --lib <фильтр>` и нужные `--test <имя>`.
- Аналитические эталоны физики с допуском 10%: `tests/physics_reference.rs`.
- Опрокидывание блока и размеры: `tests/bulk_tipping.rs` (`--ignored` для замеров времени).
- Балка против решателя ячеек: `tests/beam_equivalence.rs`.
- Область сцены, шагаемая как балка (`Scene::reduce_to_beam`, `src/scene/beam_region.rs`): `tests/beam_region.rs`.
- Свежие результаты прогонов и их логи: `VALIDATION_2026-11-05.md`, `validation/live-tests/`.

## Модули `src/`

**Механика и решатель.** `solver` (неявный шаг, контакт, трение, ячейки с вращением),
`cell_two_level` (параллельный многоуровневый предобуславливатель 6×6), `multigrid`
(трансляционный), `banded`, `contact_constraint`, `collision`, `fracture` (закон связи и
учёт энергии), `aggregation` (жёсткий дальнее поле), `cuda_solver` (необязательный путь
NVIDIA), `electrical`.

**Уровни физики и бюджет.** `budget` (регулятор: на каком уровне считать область, не
замедляя и не пропуская время), `beam` (сокращённая модель T2: балки и деревья балок,
переход к ячейкам и обратно), `aggregation` (T1 жёсткие тела).

**Материя и химия.** `material`, `material_asset`, `voxel`, `recipes`, `recipe_data`
(реакции как данные, горение, дубление, гниение), `combustion`, `scene_welding`.

**Живое.** `plant` (рост по ресурсам и событиям, геном, рубка), `creature` (датчики из
состояния сцены, учёт энергии, импульсная сеть, обучение), `skeletal_actuator` (силы по
позе скелета), `procedural_animation`, `world` (мир из сида, окно физической области),
`world_physics`.

**Сцена и документы.** `scene` (состояние, API, чекпоинт `.vxstate`), `documents` (`.vxm`,
`.vxscene`, `.vxproj`, ручные связи, MakeUnique), `scene_presets`, `mesh_import`,
`model_export`, `model_history`.

**Окно и наблюдение.** `render`, `ui`, `ui_text`, `editor_settings`, `physics_metrics`,
`runtime_metrics`, `live_tests`, `live_test_feed`.

## Бинарные файлы `src/bin/`

Основные: `voxel_editor`, `voxel_editor_mcp`, `voxel_physics_lab`, `voxel_test_viewer`
(диагностический просмотр, не часть продуктового пути). Остальные — воспроизводимые
записи и замеры конкретных механик: `*_capture` (трение, плавление, сварка, усталость,
электричество, тепловое расширение и т. д.), `*_probe`, `active_rev_ladder`,
`gpu_cell_probe` (синтетический замер умножения на GPU, не симуляция), `gpu_info`.

## Переменные окружения (решатель)

| Переменная | Эффект |
| --- | --- |
| `VOXEL_FACE_CELLS=1` | включить вращение ячеек при любом размере сцены |
| `VOXEL_BOND_ONLY=1` | запретить ячейки (трансляционный решатель, вращение блокируется) |
| `VOXEL_CELL_TWO_LEVEL=1` | принудительно многоуровневый предобуславливатель вместо скайлайна |
| `VOXEL_PROFILE_STEP=1` | печатать разбивку времени шага |
| `VOXEL_SOLVER_BACKEND=cuda\|cpu` | выбор решателя трансляционного пути |
| `VOXEL_DISABLE_AUTO_AGGREGATION=1` | отключить автоматическое укрупнение покоящихся тел |

Ячейки по умолчанию включаются до 4096 механических REV (`CELL_DOF_MAX_REVS` в
`solver.rs`); выше действует трансляционный решатель.

## Чем документы отличаются

- `WORLD_PARADIGM.md` — что должен уметь мир (цели, допуски, принципы).
- `DECISIONS_2026-11-05.md` — зафиксированные решения пользователя.
- `INTEGRATION_PLAN_2026-11-05.md` — интерфейс, существа, растения, путь оптимизации,
  бюджет 1–5 мс, четыре уровня физики, механизмы, песочница, журнал слияний.
- `VALIDATION_2026-11-05.md` — измерения, их условия и ограничения.
- `OPTIMIZATION_PLAN_2026-11-05.md` — архитектурный план оптимизации решателя.
- `ENGINE_ROADMAP.md`, `PROGRESS_2026-10-12.md` — рабочая хроника и состояние.
- `AGENTS.md` — правила для исполнителей.
